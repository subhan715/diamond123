⬆ Restore from Backup

Use this when setting up on a new laptop, or to load a previous backup. Warning: this replaces all data currently on THIS computer with the data from the backup file.

For safety, a copy of whatever was here before is automatically saved next to the software before restoring, just in case.

📋 How to move to a new laptop — step by step

  1. On your old laptop: open this Backup & Restore page, enter the password, click Download Backup File. Save it somewhere (USB drive, email, cloud drive).
  2. On your new laptop: install the software fresh (unzip the folder, run the Start file, following the README as usual).
  3. Open the new install in a browser, go to Backup & Restore in the sidebar.
  4. Enter the password, choose the backup file you saved, click Restore This Backup.
  5. Done — your inventory, orders, invoices, and deliveries are all there on the new laptop.

The backup password is set in the file config.py in the software folder. Only people who know this password can download or restore a backup, since restoring replaces all current data.
